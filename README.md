# Flask URL Shortener

A modern URL shortener built with Flask and SQLite.

## Features

- Generate random short URLs
- Custom aliases
- Click analytics
- URL validation
- SQLite persistence
- Dashboard
- Copy to clipboard
- Statistics page

## Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python3 main.py# Flask URL Shortener
