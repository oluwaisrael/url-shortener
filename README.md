# URL Shortener

A simple URL shortener built with Flask.

## USE

- Generate unique short URLs
- Redirect to original URLs
- Persist URLs using JSON storage

## Tech Stack

- Python
- Flask
- HTML

## Installation

```bash
git clone <repo-url>
cd URL_SHORTENER
pip install -r requirements.txt
python main.py
```

Visit:

http://127.0.0.1:5000
